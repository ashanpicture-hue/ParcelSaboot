# Saboot

Marketing site for Saboot (ثبوت), a packing and return video tool for Pakistani online sellers.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The page lives in `src/SabootLanding.jsx`. It is a single React component with its own styles.
